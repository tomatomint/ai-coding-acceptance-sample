# AIの完了報告を理由と証拠で確認する — 無料Sample

AIに開発を依頼しているものの、差分やlogだけでは次に進んでよいか分からない方向けです。AIが5つの観点で確認し、人には「問題・対応・理由・未確認事項」を日本語で示します。

## 使い方

1. [無料Sampleをダウンロード]({{FREE_SAMPLE_URL}})する。
2. 引用部分の対象変更・確認段階・許可操作を埋め、開発中のAIへ渡す。
3. 報告を読み、意図や影響についての質問へ答える。分からなければ聞き返す。
4. 技術的な証拠不足はAI側の追加確認へ戻す。仕様への同意は本番反映許可ではありません。

AIが対象repoを読める環境で使います。codeの正しさの保証を人に求める道具ではありません。入門教材、security監査、操作の自動化ではなく、安全性を保証しません。所要時間・時短効果は未検証です。
